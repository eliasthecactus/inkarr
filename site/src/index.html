Your reading list, on autopilot.

Inkarr is a collection manager for ebooks and audiobooks in the spirit of the *arr apps. Tell it which books you want. It searches your sources, hands releases to your download client, and files the result into your library.

How it works

The same loop you know from the *arr apps, rebuilt around books and their quirks: editions, formats, series and narrators.

WantAdd a book from Open Library, as an ebook, an audiobook or both.
SearchEvery enabled indexer is queried. Releases are scored and filtered.
GrabThe best release goes to a client that speaks its protocol (torrent or DDL).
ImportFinished files are hardlinked, renamed and filed as Author/Title.
NotifyCalibre, Audiobookshelf or a webhook learn about the new book.

Built for books

Movies have tidy scene names. Books don't, so most of Inkarr's work goes into matching releases to the right book.

🧩

Everything is a plugin

Indexers, download clients, connections, metadata sources, scheduled tasks, API routes, even UI pages. The core only orchestrates.

🧲

Torrent and DDL

Releases carry a protocol. Torrents go to qBittorrent. Direct links use the built-in downloader or JDownloader for file hosters.

🎧

Ebooks and audiobooks

Want either or both for the same title. Separate formats, categories, root folders and naming for each.

🎯

Transparent matching

Interactive search shows every release with its score and the exact reason it would be rejected. No black box.

🔗

Hardlinks by default

Torrents keep seeding and your library takes no extra space. Remote path mapping covers Docker setups.

📦

One container

A single multi-arch image on GHCR (amd64 + arm64), SQLite inside, no external database.

Write a plugin in one file

Describe your settings and implement a small interface. Inkarr renders the settings form, stores instances, adds a Test button and calls you when needed.

Plugin guide → 
import { definePlugin } from '@inkarr/sdk';

export default definePlugin({
  id: 'my-indexer',
  name: 'My Indexer',
  version: '1.0.0',
  setup(ctx) {
    ctx.registerIndexer({
      type: 'my-indexer',
      name: 'My Indexer',
      fields: [{ key: 'url', label: 'URL', type: 'url' }],
      create: (settings) => ({
        protocol: 'ddl',
        mediaTypes: ['ebook'],
        test: async () => ({ ok: true }),
        search: async (q) => [/* releases */],
      }),
    });
  },
});
