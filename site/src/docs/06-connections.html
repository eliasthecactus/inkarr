Events

Every connection has two switches, added by the core:

  • On grab (off by default): a release was sent to a download client.
  • On import (on by default): files were placed in your library.

A connection that fails is logged but never blocks the import.

Calibre

Runs calibredb add for every imported ebook. All formats of one book are added in a single call, so Calibre merges them into one entry. Title and author come from Inkarr's metadata.

FieldDescription
LibraryA local library folder (Calibre desktop must be closed), or a content server URL such as http://calibre:8080/#books, where books is the library id.
Username / PasswordContent server credentials. Enable Require username and password and allow write access in the server settings.
TagsAdded to every new book, e.g. inkarr.
Allow duplicatesPasses --duplicates.
calibredb pathDefault calibredb on $PATH. On macOS: /Applications/calibre.app/Contents/MacOS/calibredb.

Docker: the Inkarr image doesn't include Calibre, which is over 300 MB. Two options:

  • Run Calibre (e.g. linuxserver/calibre) with the content server enabled, and use Inkarr from source or a custom image that has calibredb installed.
  • Use Calibre-Web-Automated. Set Inkarr's ebook library to CWA's ingest folder and no connection is needed, because CWA imports whatever lands there.

Audiobookshelf

Starts a library scan after an import so new books appear right away.

FieldDescription
URLe.g. http://audiobookshelf:13378
API tokenABS → Settings → API Keys (or the token from Settings → Users → your user on older versions).
LibrariesNames or IDs, comma-separated. Empty scans every book library (podcast libraries are skipped).
Scan afterAudiobook imports (default), ebook imports, or both. ABS can also manage ebooks.

Point the ABS library at the same folder as Inkarr's audiobook root, mounted at a path ABS can see.

Webhook

Sends a JSON payload to any URL, which makes it easy to connect anything else: Kavita, Home Assistant, n8n, ntfy, Discord bridges and so on.

{
  "eventType": "import",          // "grab" | "import" | "test"
  "instance": "inkarr",
  "date": "2026-11-14T20:15:03.120Z",
  "book": {
    "id": 12,
    "title": "Frankenstein",
    "author": "Mary Shelley",
    "year": 1818,
    "mediaType": "ebook",
    "isbn": ["9780141439471"]
  },
  "folder": "/data/media/books/Mary Shelley/Frankenstein (1818)",
  "files": ["/data/media/books/Mary Shelley/Frankenstein (1818)/Mary Shelley - Frankenstein.epub"]
}

Grab events contain book and release (title, protocol, indexer, size…) instead of folder/files.

Kavita, Komga and others

There are no dedicated plugins yet. Most of these apps scan their folders on a schedule, and a webhook can trigger an immediate scan through their APIs. Dedicated connection plugins are small, and a good first contribution: see Connection plugins.
