Authentication

When INKARR_API_KEY is set, send it as an X-Api-Key header (or ?apikey=). Without it, the API is open. Errors come back as { "error": "message" } with a 4xx/5xx status.

curl -H "X-Api-Key: $KEY" http://localhost:8585/api/books

Books

EndpointDescription
GET /booksAll books in the library.
GET /books/:idOne book.
POST /booksAdd. Body: { book: MetadataBook & { source }, mediaTypes: ["ebook","audiobook"], monitored?, search? }. Returns the created rows (one per media type).
PUT /books/:idUpdate { monitored?, status? }.
DELETE /books/:idRemove from library. Files stay on disk.
POST /books/:id/searchInteractive search. Returns { releases: ScoredRelease[], errors: string[] }.
POST /books/:id/auto-searchSearch and grab the best release. Returns { grabbed: title | null }.
GET /books/:id/historyHistory for one book.
POST /grabGrab a specific release: { bookId, release }.

Metadata

GET /metadata/search?term=…&provider=…Search the metadata provider. Each result includes inLibrary entries.

Activity

GET /queueActive, warning and failed downloads with their book.
DELETE /queue/:id?deleteData=trueRemove. Optionally removes the item and its data in the client too.
GET /history?limit=200Global history.

Providers

:kind is indexer, downloadClient or connection.

GET /schema/:kindInstalled provider types with their settings fields.
GET /providers/:kindConfigured instances (secrets masked).
POST /providers/:kindCreate: { type, name, enabled, priority, settings }.
PUT /providers/:kind/:idUpdate. Sending ******** for a secret keeps the stored value.
DELETE /providers/:kind/:idDelete.
POST /providers/:kind/testTest unsaved settings. Returns { ok, message }.

Settings

GET /settings{ settings, defaults, metadataProviders }
PUT /settingsPartial update of core settings.

System

GET /system/statusVersion, uptime, data directory.
GET /system/pluginsDiscovered plugins, what they contribute, and load errors.
PUT /system/plugins/:id{ enabled }. Takes effect after a restart.
GET /system/tasksTasks with last/next run.
POST /system/tasks/:id/runRun now. Core ids: refresh-downloads, rss-sync, search-wanted.
GET /system/logsLast 1000 log entries, newest first.

Plugin routes

Plugins may add routes under /api/plugins/<plugin-id>/…. See the plugin's own docs.
