Requirements

  • Docker (or Node.js 22+ to run from source).
  • For torrents: qBittorrent 4.1 or newer with the Web UI enabled, plus an indexer, usually through Prowlarr or Jackett.
  • For direct downloads: nothing extra. Install JDownloader 2 only if you need file hosters.
  • Optional: Calibre, Audiobookshelf, or anything else that should hear about new books.

Install with Docker

Images are published to the GitHub Container Registry for linux/amd64 and linux/arm64:

TagMeaning
latestMost recent release (v* git tag).
0.1, 0.1.0Pinned release versions.
developBuilt from every commit to main. May break.
docker run -d --name inkarr \
  -p 8585:8585 \
  -e TZ=Etc/UTC \
  -v /srv/inkarr/config:/config \
  -v /srv/data:/data \
  --user 1000:1000 \
  --restart unless-stopped \
  ghcr.io/eliasthecactus/inkarr:latest

Then open http://<host>:8585.

docker compose

The repository includes an example docker-compose.yml with Inkarr, qBittorrent, Prowlarr and Audiobookshelf. The key idea is that every container mounts the same /data folder:

/srv/data
├── torrents/          ← qBittorrent downloads here
│   ├── inkarr-books/
│   └── inkarr-audiobooks/
├── ddl/               ← direct downloads
└── media/
    ├── books/         ← Inkarr ebook root
    └── audiobooks/    ← Inkarr audiobook root (Audiobookshelf reads this)

When the download folder and the library are on the same filesystem and mount, Inkarr hardlinks instead of copying. Imports are instant, take no extra space, and torrents keep seeding.

First run walkthrough

1. Media management

Go to Settings → Media Management and set the Ebook library and Audiobook library folders, e.g. /data/media/books and /data/media/audiobooks. Keep the import mode on Hardlink unless you have a reason not to.

2. Download client

Go to Settings → Download Clients and click +:

  • qBittorrent for torrents: URL, username and password. Click Test.
  • Direct Download for DDL sources: set a download folder such as /data/ddl.

You can add both. Each release goes to the highest-priority client that supports its protocol.

3. Indexer

Go to Settings → Indexers and click +. For torrent indexers, choose Torznab and paste an indexer's Torznab URL and API key from Prowlarr (see Torznab). To try things without any setup, add Project Gutenberg, LibriVox or Internet Archive. They are free and legal, and they use the Direct Download client.

4. Add a book

Click Add new, search for a title, author or ISBN, and click Add. Choose Ebook, Audiobook or both. With Search now on, Inkarr searches right away and grabs the best acceptable release. Watch it under Activity → Queue.

5. Connections (optional)

Under Settings → Connect, add Calibre to put ebooks into your Calibre library, or Audiobookshelf to rescan after audiobook imports.

Run from source

git clone https://github.com/eliasthecactus/inkarr
cd inkarr
npm install
npm run dev          # API on :8585 and UI with hot reload on :5173

For a production-like build: npm run build && npm start. The server then serves the UI from apps/web/dist.

Updating

docker pull ghcr.io/eliasthecactus/inkarr:latest
docker compose up -d inkarr

Database migrations run automatically on start.
