Torznab (Prowlarr, Jackett)

Torznab is the standard search API for torrent indexers. Inkarr doesn't include site-specific scrapers. Instead it talks Torznab to an indexer manager, which handles logins, Cloudflare and site quirks.

With Prowlarr

  1. In Prowlarr, add your indexers as usual.
  2. Open an indexer and copy its Torznab feed URL, e.g. http://prowlarr:9696/3/. Copy your API key from Settings → General.
  3. In Inkarr, go to Settings → Indexers → + → Torznab, paste the URL and API key, choose what it is used for, and click Test.

Repeat for each indexer. Use Use for to send ebook searches only to book trackers and audiobook searches only to audiobook trackers.

Results in 3xxx categories are treated as audiobooks, and results in 7xxx/8xxx as ebooks, unless the release name says otherwise.

Search and RSS

Torznab supports both: interactive and automatic search use t=search&q=…, and RSS sync fetches the newest items per category. Turn either off per indexer with Enable RSS and Enable search.

Project Gutenberg

More than 70,000 public-domain ebooks from gutenberg.org’s official OPDS catalog. Releases are ddl links to the EPUB and/or Kindle (AZW3) file. You need a DDL download client, such as the built-in Direct Download.

FieldDescription
FormatsEPUB, Kindle (AZW3) or both.
Mirror URLAdvanced. Use a Gutenberg mirror instead of gutenberg.org.

LibriVox

Free public-domain audiobooks recorded by volunteers. Each release is a zip of MP3 tracks, and the importer extracts it automatically. The LibriVox API only supports “title starts with” searches, so Inkarr sends the book's main title.

Internet Archive

Public-domain books scanned by libraries and openly licensed audiobooks from archive.org, downloaded directly (DDL). Ebooks come as EPUB and/or PDF; audiobooks come as a zip of MP3 tracks that archive.org builds on the fly and Inkarr extracts on import.

What it searches: only curated public-domain collections (American Libraries, Canadian Libraries, California Digital Library, European Libraries, Library of Congress, Biodiversity Heritage Library, the Gutenberg mirror and LibriVox), plus items with an explicit Creative Commons or public-domain license. Borrow-only “lending library” books and user uploads outside these collections are never included. Modern copyrighted books therefore return no results, as intended.

Older scans often carry the full historical title (“Frankenstein; or, The Modern Prometheus”). Inkarr only requires the main title, the part before :, ; or “, or”, to appear in a release name.

Adding other sources

Any website or API can become an indexer: write a plugin that returns Release objects (see Plugin development → Indexer). A release only needs a title, a protocol and a downloadUrl. For ddl releases, return the direct file URL, or a hoster URL if you use JDownloader.

Only add sources you have the right to download from. Inkarr is a tool for managing your collection, and you are responsible for the content you fetch with it.
